# crm_gestor
O CRM GESTOR é o sistema de gestão da AROS ARTE DIGITAL: frente de caixa (PDV) com cupom, controle de caixa, estoque, compras, fiado, clientes, orçamentos, projetos, financeiro e relatórios. É um arquivo só ( index.html ) que roda no navegador, funciona sem internet e guarda os dados no próprio computador. https://crmgestoraros.netlify.app/
